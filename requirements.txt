# Pinned to the versions this pipeline was last trained and exported with,
# on Python 3.11 (see .python-version). These are exact pins rather than
# ranges because two of them change results rather than just behaviour:
#
#   pillow      - PIL's default resample filter is what every export and
#                 evaluation path uses to resize to 224x224. A future Pillow
#                 that changes that default silently changes model scores,
#                 with nothing failing to indicate it.
#   albumentations - train.py's AUGMENT pipeline uses num_shadows_limit,
#                 num_holes_range and quality_range, which are 2.x-only. The
#                 previous `albumentations>=1.4` would happily resolve to a
#                 1.x that raises TypeError on import.
#
# Regenerate deliberately after upgrading anything, and re-run the export and
# the app regression set before trusting the numbers.
